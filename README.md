# abbex
A regex-based chrome extension to compile and quickly access definitions in a sticky sidebar. Works on popular journals and libraries.
Extension currently works on: <br>
www.academic.oup.com <br>
www.journals.plos.org <br>
www.link.springer.com <br>
www.onlinelibrary.wiley.com <br>
www.pmc.ncbi.nlm.nih.gov <br>
www.pubmed.ncbi.nlm.nih.gov <br>
www.cell.com <br>
www.nature.com <br>
www.ncbi.nlm.nih.gov <br>
www.ovid.com <br>
www.science.org <br>
www.sciencedirect.com <br>
www.tandfonline.com <br>
www.biorxiv.org
