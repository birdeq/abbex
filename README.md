# abbex
A regex-based chrome extension to compile and quickly access definitions in a sticky sidebar. Works on popular journals and libraries.
Extension currently works on:
*://academic.oup.com/*
*://journals.plos.org/*
*://link.springer.com/*
*://onlinelibrary.wiley.com/*
*://pmc.ncbi.nlm.nih.gov/*
*://pubmed.ncbi.nlm.nih.gov/*
*://www.cell.com/*
*://www.nature.com/*
*://www.ncbi.nlm.nih.gov/*
*://www.ovid.com/*
*://www.science.org/*
*://www.sciencedirect.com/*
*://www.tandfonline.com/*
